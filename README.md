## Як запустити домашнє завдання

1. Відкрийте проєкт в IntelliJ IDEA та запустіть `Main`.
2. Виберіть номер ДЗ (1–5 у меню), а потім номер завдання (1–5).
3. Або запустіть потрібний клас `Task...` у пакеті `semester1.practiceNN.homework`.
