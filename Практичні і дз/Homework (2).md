> [!IMPORTANT]
> **Ключова вимога завдання:** Обов'язкове використання скорочених логічних операторів (`&&`, `||`, `!`) для організації «лінивих» перевірок (short-circuit). Ділення на термін кредиту має бути надійно захищене від нульового значення в одній логічній умові!

   - Інакше $\to$ стандартна ставка $21.0\%$.
5. **Загальне рішення:**

### Рівень 4: Поглиблений (5 балів)
#### 📝 Завдання 4: Інтелектуальний клімат-контроль на базі `modern switch` та `yield`

- **Клас для виконання:** `Task4SmartHomeClimate` (файл `Task4SmartHomeClimate.java`)
- **Рекомендований пакет:** `semester1.practice03.homework` (або `semester1.practice03`)
- **Бали за завдання:** **5 балів**
- **Ключові теми:** `Scanner`, Modern switch expression зі стрілками `->` та блоками `yield`, `if-else-if ladder`, поєднання логічних умов `&&`, `||`, `!`, рядкові методи `.equalsIgnoreCase()`.

**Контекст:** Контролер системи "Smart Home" збирає показники з датчиків будинку і керує роботою газового котла, інверторного кондиціонера, зволожувача та припливної вентиляції.

**Що необхідно зробити:**
1. Зчитати з консолі телеметричні дані:
   - Поточна температура в будинку (`double currentTemp`).
   - Бажана температура (`double desiredTemp`).
   - Вологість повітря у відсотках (`int humidity`).
   - Сезон року (рядок: `"зима"`, `"літо"`, `"міжсезоння"`).
   - Режим роботи будинку (`int mode`: `1` — Standby/Звичайний, `2` — Eco/Енергозбереження, `3` — Party/Гості, `4` — Night/Ніч, `5` — Vacation/Відпустка).
   - Прапорець відкритих вікон (`boolean isWindowOpen`).
2. **Short-circuit перевірка безпеки:**
   Якщо `isWindowOpen && (mode != 5)`, система повинна зафіксувати аварійний стан: негайно вимкнути кліматичні установки та вивести:
   `"ПОПЕРЕДЖЕННЯ: Відчинені вікна! Обігрів та кондиціонування примусово заблоковано!"`
3. **Розрахунок скоригованої цільової температури через Modern Switch Expression з `yield`:**
   Залежно від обраного `mode` обчисліть `effectiveTargetTemp`:
   - `1` (Standby) $\to$ повертає значення `desiredTemp` без змін.
   - `2` (Eco) $\to$ блок коду `{ ... }`: якщо сезон `.equalsIgnoreCase("зима")`, знизити цільову температуру на 2.0°C; якщо `"літо"` — підвищити на 2.0°C; для інших сезонів зміна 0.0°C. Повернути значення через **`yield`**.
   - `3` (Party) $\to$ знизити цільову температуру на 1.5°C (через додаткове тепло від людей).
   - `4` (Night) $\to$ повернути комфортні для сну 19.0°C.
   - `5` (Vacation) $\to$ блок коду `{ ... }`: черговий захисний режим. Якщо сезон "зима" $\to$ `yield 12.0;` (захист труб від замерзання), інакше `yield 28.0;`.
   - `default` $\to$ повернути `desiredTemp`.
4. **Ухвалення рішення щодо терморегуляції (`if-else-if ladder`):**
   - Якщо різниця $(\text{currentTemp} - \text{effectiveTargetTemp}) > 0.5$ $\to$ `"Кондиціонер УВІМКНЕНО (Охолодження)"`.
   - Якщо різниця $(\text{effectiveTargetTemp} - \text{currentTemp}) > 0.5$ $\to$ `"Опалення УВІМКНЕНО (Обігрів)"`.
