> [!WARNING]

- **Рекомендований пакет:** `semester1.practice02.homework` (або `semester1.practice02`)

**Контекст:** Скласти комплексну систему логічних перевірок для геометрії трикутника.

> [!CAUTION]
> **Головна умова:** **Категорично заборонено використовувати конструкції розгалуження `if-else`, `switch` та тернарний оператор `? :`!** Всі умови повинні бути сформульовані виключно за допомогою операторів порівняння (`==`, `>`, `<`), логічних зв'язок (`&&`, `||`, `!`) та збережені у змінні типу `boolean`.

**Вхідні дані:**
- Три довжини сторін трикутника: `double a = 3.0; double b = 4.0; double c = 5.0;`

**Що необхідно зробити:**
1. Перевірити, чи може існувати такий трикутник (теорема нерівності трикутника: сума будь-яких двох сторін має бути строго більшою за третю):
   `boolean exists = (a + b > c) && (a + c > b) && (b + c > a);`
2. Перевірити, чи є він рівностороннім ($a = b = c$).
3. Перевірити, чи є він рівнобедреним (хоча б дві сторони рівні між собою: $a = b$ або $b = c$ або $a = c$).
4. Перевірити, чи є він прямокутним за теоремою Піфагора (з урахуванням, що гіпотенузою може виявитися будь-яка зі сторін: $a^2 + b^2 = c^2$ або $a^2 + c^2 = b^2$ або $b^2 + c^2 = a^2$).
   *(Підказка: скористайтеся `Math.pow()`)*.
5. Вивести значення кожної булевої змінної у консоль.

### Рівень 4: Поглиблений (5 балів)
#### 📝 Завдання 4: Формула Герона та геометрія вписаного/описаного кіл

- **Клас для виконання:** `Task4HeronGeometry` (файл `Task4HeronGeometry.java`)
- **Рекомендований пакет:** `semester1.practice02.homework` (або `semester1.practice02`)
- **Бали за завдання:** **5 балів**

**Контекст:** Задача вимагає точного використання методів класу `Math` (`Math.sqrt`, `Math.pow`, константи `Math.PI`), а також особливої пильності щодо пріоритету операцій та ділення дробів.

**Вхідні дані:**
- Сторони трикутника: `double a = 7.0; double b = 8.0; double c = 9.0;`

**Що необхідно зробити:**
1. Обчислити периметр трикутника: $P = a + b + c$.
2. Обчислити напівпериметр: $p = \frac{P}{2.0}$.
3. Обчислити площу за формулою Герона:
   $$S = \sqrt{p \cdot (p - a) \cdot (p - b) \cdot (p - c)}$$
4. Обчислити радіус вписаного кола:
   $$r = \frac{S}{p}$$
   та площу вписаного круга: $S_{\text{впис}} = \pi \cdot r^2$.
5. Обчислити радіус описаного кола:
   $$R = \frac{a \cdot b \cdot c}{4 \cdot S}$$
   *(Увага на знаменник: обов'язково пишіть у дужках `(4.0 * S)`!)*
   та площу описаного круга: $S_{\text{опис}} = \pi \cdot R^2$.
6. Вивести зведену геометричну довідку.

**Очікуваний результат у консолі:**

Напівпериметр (p):          12.0
Площа трикутника (S):       26.832815729997478 кв. од.
Радіус вписаного кола (r):  2.23606797749979
Площа вписаного круга:      15.707963267948969 кв. од.

- [ ] Чи оголошено курс та відсоток комісії як **`final`** константи у стилі `UPPER_SNAKE_CASE` (`EXCHANGE_RATE`, `COMMISSION_PERCENT`).
- [ ] Чи використано саме **`Math.round()`** для розрахунку готівки, а не просте відкидання дробу через `(int)`.
- [ ] Чи коректна конкатенація чека (чи є пробіли, чи не злипаються числа з назвами валют `UAH`/`USD`).

#### 🔍 Завдання 2 (`Task2NumberAnalysis`):
- [ ] **КРИТИЧНО:** Чи не використав студент рядок `String.valueOf(number)` або `StringBuilder.reverse()`? Завдання перевіряє виключно знання арифметики (`/ 100`, `/ 10 % 10`, `% 10`).
- [ ] Чи зібрано перевернуте число як числове значення через арифметичну формулу (`units * 100 + tens * 10 + hundreds`), а не просто виведено в консоль трьома послідовними `print`.
- [ ] Чи парність визначена виразом `sum % 2 == 0` зі збереженням у змінну `boolean`.

#### 🔍 Завдання 3 (`Task3TriangleClassifier`):
- [ ] **КРИТИЧНО:** **Повна відсутність операторів `if`, `else`, `switch` та тернарного оператора `? :`!** Усі перевірки мають бути суто булевими виразами: `boolean exists = ...;`.
- [ ] Чи правильна теорема нерівності трикутника: мають виконуватися **всі три умови одночасно** через оператор `&&` (`a + b > c && a + c > b && b + c > a`).
- [ ] Чи теорема Піфагора враховує, що гіпотенузою може бути **будь-яка** зі сторін ($a$, $b$ або $c$), об'єднані через `||`.

#### 🔍 Завдання 4 (`Task4HeronGeometry`):
- [ ] **Пастка дужок у знаменнику:** вираз $R = \frac{abc}{4S}$ у Java записується обов'язково як `(a * b * c) / (4.0 * s)`. Якщо студент написав `... / 4.0 * s`, результат помножиться на $S$ замість ділення — це груба математична помилка.
- [ ] Чи використано системну константу **`Math.PI`**, а не захардкоджене наближення `3.14`.
- [ ] Чи використано `Math.sqrt(...)` для кореня та `Math.pow(..., 2)` для квадратів.

#### 🔍 Завдання 5 (`Task5RpgHero`):
- [ ] **Генерація діапазону:** формула має бути саме `(int)(Math.random() * (18 - 8 + 1)) + 8`. Зверніть увагу на дужки приведення типу: `(int)(...)` має охоплювати весь вираз множення, інакше `(int)Math.random()` перетвориться на `0`!
- [ ] **Кубики:** гравець має кидати **два окремих кубики `d6`**, тобто два виклики `(int)(Math.random() * 6) + 1`, а не один кубик від 2 до 12 (у теорії ймовірностей сума двох кубиків дає пік на числі 7, а один кубик має плоский розподіл).
