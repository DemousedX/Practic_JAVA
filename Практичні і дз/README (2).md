# Практична робота №1: Перший проєкт, перший клас та базове виведення в консоль

## Мета роботи
- Ознайомитися із середовищем розробки **IntelliJ IDEA**.
- Навчитися створювати проєкт та структуру пакетів згідно з конвенціями Java.
- Створити свій перший Java-клас та точку входу — метод `main`.
- Опанувати команди консольного виведення `System.out.println()` та `System.out.print()`.
- Вивчити екранування спеціальних символів (`\n`, `\t`, `\"`, `\\`).
- Навчитися виводити числа та обчислювати базові арифметичні вирази.
- **Важливе правило цієї практики:** *не використовувати змінні та конкатенацію рядків (`+` між текстом)* — оскільки ці теми вивчатимуться на наступних лекціях.

## 1. Покрокова інструкція: Створення першого проєкту та класу

### Крок 1. Створення проєкту в IntelliJ IDEA
1. Відкрийте **IntelliJ IDEA**.
2. На початковому екрані натисніть **New Project** (або у верхньому меню: **File -> New -> Project...**).
3. У вікні налаштування нового проєкту вкажіть:
   - **Name**: вкажіть назву проєкту (наприклад, `Practice_Students`).
   - **Location**: виберіть папку на диску для збереження проєкту.
   - **Language**: виберіть **Java**.
   - **Build system**: оберіть **IntelliJ** *(для початку працюємо виключно на стандартній системі збірки IntelliJ, без сторонніх збирачів на кшталт Maven чи Gradle)*.
   - **JDK**: переконайтеся, що вибрано встановлену версію Java (рекомендовано Java 17 або Java 21). Якщо JDK немає, натисніть *Download JDK*.
   - **Add sample code**: можна зняти позначку (щоб створити свій перший клас власноруч).
4. Натисніть **Create**.

---

### Крок 2. Розуміння структури проєкту в IntelliJ
Після створення проєкту зліва на панелі `Project` (або за комбінацією `Alt + 1` / `Cmd + 1`) ви побачите стандартну структуру:
```
Practice_Students/
├── .idea/                  # Системні налаштування середовища IntelliJ IDEA
├── src/                    # Головна папка для вашого коду (Sources Root, підсвічена синім)
└── Practice_Students.iml   # Файл конфігурації модуля проєкту
```
> [!IMPORTANT]
> Весь вихідний код на Java створюється виключно всередині синьої папки **`src`**.

---

### Крок 3. Створення пакетів відповідно до Java Code Conventions
У мові Java прийнято групувати класи в **пакети** (packages), які структурують проєкт та запобігають конфліктам імен.
- **Головне правило конвенції:** назви пакетів пишуться **виключно маленькими літерами** (lowercase), без великих літер, пробілів та спецсимволів (наприклад: `semester1.practice01`).
- **Щоб створити пакет у проєкті IntelliJ:**
  1. Клікніть правою кнопкою миші на папку **`src`**.
  2. Виберіть пункт **New -> Package**.
  3. Введіть назву: `semester1.practice01` і натисніть **Enter**.

### Крок 4. Створення першого класу
1. Клікніть правою кнопкою миші на щойно створений пакет `semester1.practice01`.
2. Виберіть **New -> Java Class**.
3. Введіть ім'я класу: `Practice01` (назви класів пишуться в стилі **PascalCase** — кожне слово з великої літери) та натисніть **Enter**.
4. Створиться файл `Practice01.java`:
```java
package semester1.practice01;

public class Practice01 {

}
```

### Крок 5. Створення точки входу (метод `main`)
Будь-яка Java-програма починає своє виконання з методу `main`. 
Замість того, щоб писати довгий рядок вручну, скористайтеся шаблоном автодоповнення:
1. Всередині фігурних дужок класу `Practice01` надрукуйте слово `main` або абревіатуру `psvm`.
2. Натисніть клавішу **Tab** або **Enter**.
3. Середовище згенерує метод:
```java
package semester1.practice01;

public class Practice01 {
    public static void main(String[] args) {
        // Код програми пишеться тут
    }
}
```

### Крок 6. Перша команда виведення: `System.out.println`
Для виведення тексту в консоль використовується команда:
```java
System.out.println("Привіт, світе!");
```
- **Гаряче скорочення в IntelliJ IDEA:** напишіть `sout` і натисніть **Tab** або **Enter**.
- Рядок тексту обов'язково береться в **подвійні лапки**: `"текст"`.
- Кожна інструкція в Java завершується **крапкою з комою** `;`.

### Крок 7. Запуск програми
1. Зліва від рядка `public class Practice01` або `public static void main` натисніть зелену стрілочку (**Run** `▶`).
2. Або скористайтеся комбінацією клавіш: **Ctrl + Shift + F10** (Windows/Linux) або **Ctrl + R** (macOS).
3. Знизу відкриється вікно **Run (консоль)**, де з'явиться результат виконання вашої програми.

## 2. Теоретичні відомості для виконання завдань

### 1. `System.out.println()` проти `System.out.print()`
- `System.out.println("Текст");` — друкує текст і **переводить курсор на новий рядок**.
- `System.out.print("Текст");` — друкує текст, але **залишає курсор у тому ж рядку**. Наступне виведення продовжуватиметься поруч.
- `System.out.println();` — порожній виклик без аргументів; просто створює порожній новий рядок (натискання Enter).

**Приклад:**
```java
System.out.print("Привіт, ");
System.out.print("як ");
System.out.println("справи?");
System.out.println("Все чудово!");
```
*Вивід у консолі:*
```text
Привіт, як справи?
Все чудово!
```

---

### 2. Керуючі послідовності (Escape Sequences)
Якщо всередині тексту в лапках вказати зворотний слеш `\`, Java інтерпретує наступний символ як спеціальну команду:
- `\n` — перехід на новий рядок (newline).
- `\t` — горизонтальна табуляція (відступ на кілька пробілів для вирівнювання таблиць).
- `\"` — подвійні лапки всередині тексту (щоб компілятор не сприйняв їх за кінець рядка).
- `\\` — виведення символу зворотного слешу `\`.

**Приклад:**
```java
System.out.println("Рядок 1\nРядок 2");
System.out.println("Слово1\tСлово2");
System.out.println("Він сказав: \"Java чудова!\"");
System.out.println("Шлях: C:\\Java\\Projects");
```

### 3. Виведення чисел та простих арифметичних обчислень
Числа та математичні вирази пишуться **без лапок**!
Якщо написати `"5 + 3"`, Java надрукує текст `5 + 3`.
Якщо написати `5 + 3`, Java спочатку обчислить значення і надрукує `8`.

**Приклад:**
```java
System.out.println(42);         // Ціле число
System.out.println(3.1415);     // Дробове число
System.out.println(10 + 5);     // Додавання: виведе 15
System.out.println(20 - 7);     // Віднімання: виведе 13
System.out.println(6 * 8);      // Множення: виведе 48
System.out.println(15 / 3);     // Ділення цілих чисел: виведе 5
System.out.println(7 / 2);      // Цілочисельне ділення: виведе 3 (без дробової частини!)
System.out.println(7.0 / 2.0);  // Ділення з комою: виведе 3.5
System.out.println((2 + 3) * 4);// Вираз із дужками: виведе 20
```

> [!CAUTION]
> **Увага:** У цій практичній роботі **ЗАБОРОНЕНО** писати конструкції на кшталт:
> `System.out.println("Результат: " + (5 + 3));`
> Оскільки конкатенацію рядків (`+`) ви ще не проходили на лекціях. Якщо потрібно вивести підпис і результат, використовуйте два виклики:
> ```java
> System.out.print("Результат: ");
> System.out.println(5 + 3);
> ```

#### Завдання 40: Підсумкове творче завдання — Товарний чек
