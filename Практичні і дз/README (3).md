## 📚 1. Теоретичні відомості

### 1.1. Що таке змінна та навіщо вона потрібна?
Уявіть комп'ютерну пам'ять як величезну шафу з безліччю підписаних шухлядок.
**Змінна** — це саме така шухлядка, яка має:
1. **Тип даних** — визначає, що саме можна покласти в шухлядку (число, літеру чи текст) і скільки байт пам'яті це займе.
2. **Ім'я (ідентифікатор)** — назва, за якою ми звертаємося до шухлядки.
3. **Значення** — те, що в ній реально лежить на поточний момент.

Створення змінної відбувається за шаблоном:
```java
типДаних назваЗмінної = початковеЗначення;
```
Наприклад:
```java
int studentAge = 18; // Створили цілочисельну змінну studentAge зі значенням 18
```

### 1.2. Примітивні типи даних та `String`
У Java є **8 примітивних типів** (вони зберігають «чисті» значення) та окремий тип **`String`** для роботи з текстом:

| Тип даних | Розмір | Що зберігає | Приклад значення | Особливості та суфікси |
| :--- | :--- | :--- | :--- | :--- |
| `byte` | 1 байт | Ціле число (-128 до 127) | `byte b = 100;` | Економія пам'яті в масивах |
| `short` | 2 байти | Ціле число (-32,768 до 32,767) | `short s = 25000;` | Рідко використовується |
| `int` | 4 байти | Ціле число (від -2 млрд до +2 млрд) | `int count = 42;` | **Стандартний вибір для цілих чисел** |
| `long` | 8 байтів | Дуже велике ціле число | `long stars = 9000000000L;` | **Обов'язковий суфікс `L`** у кінці |
| `float` | 4 байти | Дробове число (6-7 цифр точності) | `float price = 19.99f;` | **Обов'язковий суфікс `f`** у кінці |
| `double` | 8 байтів | Дробове число (15-16 цифр точності) | `double pi = 3.14159265;` | **Стандартний вибір для дробів** |
| `char` | 2 байти | Одиночний символ в **одинарних** лапках | `char grade = 'A';` | Одинарні лапки `' '`, Unicode |
| `boolean`| 1 біт | Логічне значення: `true` або `false` | `boolean isPassed = true;` | Тільки `true` або `false` (без 0/1) |
| `String` | Посилальний | Рядок тексту в **подвійних** лапках | `String name = "Олена";` | Подвійні лапки `" "`, клас Java |

> [!TIP]
> **Золоте правило вибору типу:**
> - Для цілих чисел завжди беріть **`int`** (якщо число не перевищує 2 мільярди).
> - Для чисел із плаваючою комою беріть **`double`**.
> - Для тексту — **`String`**.
> - Для логічних станів (так/ні) — **`boolean`**.

### 1.3. Константи: ключове слово `final`
Якщо значення змінної не повинно змінюватися під час роботи програми, перед типом додають слово `final`. 
Такі змінні називають **константами**, а їхні імена за конвенцією пишуть великими літерами через підкреслення (**UPPER_SNAKE_CASE**):
```java
final double PI = 3.1415926535;
final int MAX_ATTEMPTS = 3;
// PI = 3.14; // ПОМИЛКА КОМПІЛЯЦІЇ! Значення константи змінити не можна.
```

### 1.4. Приведення типів (Type Casting)
- **Неявне розширення (автоматичне):** коли менший тип перетворюється на більший без втрати даних:
  ```java
  int smallNumber = 10;
  double bigNumber = smallNumber; // 10.0 (автоматично)
  ```
- **Явне звуження (ручне):** коли більший тип поміщають у менший із можливою втратою точності. Для цього в круглих дужках вказують цільовий тип:
  ```java
  double pi = 3.99;
  int roundedPi = (int) pi; // Буде 3 (дробова частина просто відкидається, не округлюється!)
  ```

### 1.5. Правила іменування змінних (Java Naming Conventions)
1. **camelCase (верблюжий регістр):** перше слово пишеться з маленької літери, а кожне наступне слово — з великої:
   - ✅ `userAge`, `totalScore`, `isGameOver`, `studentFirstName`
   - ❌ `user_age`, `TotalScore`, `userage`, `USERAGE`
2. **Дозволені символи:** літери латиниці (`a-z`, `A-Z`), цифри (`0-9`), знак підкреслення (`_`) та знак долара (`$`).
3. **Не можна починати з цифри:**
   - ❌ `1stPlayer`
   - ✅ `firstPlayer`, `player1`
4. **Не можна використовувати зарезервовані слова Java:**
   - ❌ `int class = 5;`, `double public = 10.5;`, `boolean new = false;`
5. **Змістовні назви замість загадкових:**
   - ❌ `int a = 25; double b = 180.5;`
   - ✅ `int studentAge = 25; double userHeight = 180.5;`

### 1.6. Конкатенація рядків (Склеювання через `+`)
Оператор `+` у Java має подвійну природу:
- Якщо обидва операнди є числами, відбувається **арифметичне додавання**: `5 + 3` дасть `8`.
- Якщо хоча б один із операндів є рядком (`String`), відбувається **склеювання (конкатенація)**: `"Вік: " + 18` перетвориться на `"Вік: 18"`.

> [!CAUTION]
> **Головна пастка конкатенації (порядок зліва направо):**
> ```java
> System.out.println("Результат: " + 5 + 10);   // Виведе: Результат: 510  (текст + 5 -> "Результат: 5" + 10 -> "Результат: 510")
> System.out.println("Результат: " + (5 + 10)); // Виведе: Результат: 15   (дужки обчислюються першими!)
> System.out.println(5 + 10 + " - це сума");     // Виведе: 15 - це сума  (5 + 10 = 15, потім 15 + текст)
> ```

### 1.7. Оператори в Java

#### 1. Арифметичні оператори
- `+` додавання
- `-` віднімання
- `*` множення
- `/` ділення (якщо обидва числа `int`, ділення **цілочисельне**! `7 / 2` дорівнює `3`, а `7.0 / 2` дорівнює `3.5`)
- `%` **остача від ділення (модуль)**:
  ```java
  int remainder = 17 % 5; // 2 (тому що 17 = 5 * 3 + 2)
  int evenCheck = 8 % 2;  // 0 (парне число завжди дає остачу 0 при діленні на 2)
  int lastDigit = 257 % 10; // 7 (остача від ділення на 10 — це завжди остання цифра!)
  ```

#### 2. Скорочені оператори присвоєння (Compound Assignment)
Замість довгого запису `a = a + 5;` у Java пишуть зручніше:
- `a += 5;` (еквівалент `a = a + 5;`)
- `a -= 3;` (еквівалент `a = a - 3;`)
- `a *= 2;` (еквівалент `a = a * 2;`)
- `a /= 4;` (еквівалент `a = a / 4;`)
- `a %= 10;` (еквівалент `a = a % 10;`)

#### 3. Інкремент (`++`) та Декремент (`--`)
- `x++` або `++x` — збільшує значення `x` на 1.
- `x--` або `--x` — зменшує значення `x` на 1.
- **Різниця між префіксним і постфіксним записом:**
  - `++x` (префіксний): спочатку збільшує значення, а потім повертає результат.
  - `x++` (постфіксний): спочатку повертає поточне значення, а збільшує його лише після цього кроку!

#### 4. Оператори порівняння (повертають `boolean`: `true` або `false`)
- `==` дорівнює (`a == b`)
- `!=` не дорівнює (`a != b`)
- `>` більше (`a > b`)
- `<` менше (`a < b`)
- `>=` більше або дорівнює (`a >= b`)
- `<=` менше або дорівнює (`a <= b`)

#### 5. Логічні оператори
- `&&` — логічне **І** (AND). Вираз істинний тільки тоді, коли обидві умови істинні (`age >= 18 && hasTicket`).
- `||` — логічне **АБО** (OR). Вираз істинний, якщо хоча б одна з умов істинна (`isWeekend || isHoliday`).
- `!` — логічне **НЕ** (NOT). Інвертує значення (`!isGameOver` перетворює `false` на `true`).

### 1.8. Допоміжний математичний клас `Math`
Клас `Math` входить до стандартного пакету `java.lang`, тому його **не потрібно імпортувати**.
Всі його методи є статичними і викликаються напряму через `Math.ім'яМетоду()`:

| Метод / Константа | Що робить | Приклад виклику | Результат |
| :--- | :--- | :--- | :--- |
| `Math.PI` | Константа $\pi \approx 3.14159...$ | `Math.PI` | `3.141592653589793` |
| `Math.E` | Константа експоненти $e \approx 2.718...$ | `Math.E` | `2.718281828459045` |
| `Math.pow(a, b)` | Піднесення $a$ до степеня $b$ ($a^b$) | `Math.pow(2, 3)` | `8.0` (`double`) |
| `Math.sqrt(a)` | Квадратний корінь $\sqrt{a}$ | `Math.sqrt(25)` | `5.0` (`double`) |
| `Math.abs(a)` | Модуль (абсолютна величина) $|a|$ | `Math.abs(-15)` | `15` |
| `Math.min(a, b)` | Мінімальне з двох чисел | `Math.min(10, 20)` | `10` |
| `Math.max(a, b)` | Максимальне з двох чисел | `Math.max(10, 20)` | `20` |
| `Math.round(a)` | Математичне округлення до найближчого цілого | `Math.round(4.6)` | `5` (`long` або `int`) |
| `Math.ceil(a)` | Округлення вгору («стеля») | `Math.ceil(4.1)` | `5.0` (`double`) |
| `Math.floor(a)` | Округлення вниз («підлога») | `Math.floor(4.9)` | `4.0` (`double`) |
| `Math.random()` | Псевдовипадкове число від `0.0` (включно) до `1.0` (не включно) | `Math.random()` | `0.74281...` |

> [!IMPORTANT]
> **Універсальна формула випадкового цілого числа від `min` до `max` включно:**
> ```java
> int randomNum = (int) (Math.random() * (max - min + 1)) + min;
> ```
> *Наприклад, для кубика від 1 до 6:* `(int) (Math.random() * 6) + 1;`

## 📋 3. Критерії оцінювання та типові помилки

### Чек-лист для самоперевірки перед здачею:
1. **Код компілюється:** відсутні червоні підкреслення в середовищі розробки.
2. **Правильні типи даних:**
   - Не використовуйте `int` для ділення, де очікується дробовий результат.
   - Для грошей і точних вимірювань використовуйте `double`.
   - Не забувайте суфікс `L` для `long` та `f` для `float`.
3. **Конвенція іменування:** усі змінні написані в **`camelCase`** і мають зрозумілі назви (`totalScore`, а не `ts` чи `a`).
4. **Форматування коду:** код вирівняний за відступами (`Ctrl + Alt + L` у Windows / `Cmd + Option + L` у macOS).
5. **Конкатенація з дужками:** скрізь, де перед числами стоїть текст, арифметичні вирази взяті в круглі дужки `(a + b)`.
